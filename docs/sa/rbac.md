## วิธี implement

- JWT claim: `sub`, `name`, `role`, `branch_id` (ถ้ามี)
- ASP.NET Core **policy** ต่อ action เช่น `CanApprovePurchaseOrder`, `CanReceiveGoods`
- เงื่อนไขที่ต้องดูข้อมูล (สาขา, วงเงิน) ใช้ **resource-based authorization**: โหลด PO ก่อน แล้วเรียก `IAuthorizationService.AuthorizeAsync(user, po, "CanApprovePurchaseOrder")`
- query ที่คืนรายการ: ใส่ filter สาขาใน handler เสมอสำหรับ Staff/BranchManager (กันลืมด้วย integration test ที่ขอข้อมูลสาขาอื่นแล้วต้องได้ 403 หรือรายการว่าง)
- หน้าจอซ่อนปุ่มตามสิทธิ์ได้ แต่ **API ต้องตรวจเองทุกครั้ง** (US-002 AC 3 "เรียก API ตรงได้ 403")

### 403 หรือ 404

| กรณี | ตอบ |
| --- | --- |
| เอกสารมีอยู่ แต่เป็นของสาขาอื่น | 403 (ตาม AC ที่เขียนไว้) |
| เอกสารไม่มีอยู่จริง | 404 |
| role ทำ action นี้ไม่ได้เลย | 403 |
