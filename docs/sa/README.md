## คำถามที่ SA ต้อง clarify กับ BA

เจอตอนออกแบบข้อมูล ยังไม่มีใน AC

- [ ] **Q-SA-01 · PO หลายสาขา ผู้จัดการสาขาไหนอนุมัติ?** US-005 รวม PR หลายสาขาเป็น PO ใบเดียวต่อผู้ขาย แต่ US-002 ให้ "ผู้จัดการสาขา" อนุมัติ
      → ตัดสินชั่วคราว: ผู้จัดการอนุมัติได้เมื่อ **PO ทั้งใบส่งถึงสาขาตัวเองเท่านั้น** และยอด ≤ ฿5,000 · PO ที่ส่งหลายสาขาให้เจ้าของอนุมัติทุกยอด
      → เหตุผล: ผู้จัดการไม่ควรอนุมัติเงินที่ใช้กับสาขาอื่น
      → **กระทบ:** US-002 ต้องเพิ่ม AC · ข้อมูลเดโม PO-2026-0835 เป็น PO สาขาเดียว
- [ ] **Q-SA-02 · ใครอนุมัติ PR?** flow มีขั้น "อนุมัติ PR · ผู้จัดการสาขา" แต่ไม่มี US รองรับ
      → ตัดสินชั่วคราว: ผู้จัดการสาขาอนุมัติ PR ของสาขาตัวเอง ทำ API ไว้ก่อน หน้าจอเป็นรายการธรรมดา · เสนอเปิด US-008
- [ ] **Q-SA-03 · จุดสั่งซื้อและ max stock ตั้งต่อสาขาหรือทั้งร้าน?** (US-006 Task ถามไว้)
      → ตัดสินชั่วคราว: **ต่อสาขา** (ตาราง `product_branch_settings`) เพราะยอดขายแต่ละสาขาต่างกัน
