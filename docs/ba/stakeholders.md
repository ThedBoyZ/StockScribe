## วิธีจัดการตามกลุ่ม

| อิทธิพล / ความสนใจ | กลุ่ม | ทำอย่างไร |
| --- | --- | --- |
| สูง / สูง | เจ้าของร้าน | ให้อนุมัติ scope และ success metrics, เดโมทุก milestone |
| กลาง / สูง | จัดซื้อ, ผู้จัดการสาขา | ร่วมทดสอบ prototype และ UAT |
| ต่ำ / กลาง | พนักงานรับของ | usability test หน้ารับของบนมือถือ |
| กลาง / กลาง | บัญชี | แจ้งความคืบหน้า, ถามเรื่องการตรวจบิล |

## Role ในระบบ (ส่งต่อให้ SA ทำ RBAC)

| Role | สิทธิ์หลัก |
| --- | --- |
| Owner | ทุกอย่าง + อนุมัติ PO ทุกวงเงิน |
| BranchManager | อนุมัติ PR/PO ≤ 5,000 บาท ของสาขาตัวเอง |
| Purchasing | จัดการผู้ขาย, สร้าง/ส่ง PO |
| StoreStaff | สร้าง PR, รับของ, ปรับสต็อก เฉพาะสาขาตัวเอง |
| Admin | ผู้ใช้, สาขา, ข้อมูลสินค้า |
