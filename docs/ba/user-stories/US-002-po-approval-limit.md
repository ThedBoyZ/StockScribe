## Story

ในฐานะ **ผู้จัดการสาขา** ฉันต้องการ **อนุมัติใบสั่งซื้อที่ยอดไม่เกิน 5,000 บาทได้เอง** เพื่อให้ **ของเข้าร้านเร็วขึ้นโดยไม่ต้องรอเจ้าของทุกใบ**

## Acceptance Criteria

> ยอดที่ใช้เทียบวงเงินทุกข้อ = ยอดรวมก่อน VAT = Σ (จำนวน × ราคาต่อหน่วย) ทุกบรรทัดของ PO (ดู glossary)
> PO ที่ส่งขออนุมัติอยู่ในสถานะ PendingApproval · ระบบเลือกผู้อนุมัติจากยอดให้เอง ผู้จัดการไม่ต้องส่งต่อ

1. Given PO สถานะ PendingApproval ยอด 4,800 บาท, When ผู้จัดการสาขากดอนุมัติ, Then PO เป็น Approved และบันทึกผู้อนุมัติ + เวลาใน audit log
2. Given PO ยอด 5,000 บาทพอดี, When ผู้จัดการสาขากดอนุมัติ, Then อนุมัติได้ (ขอบเขตรวม 5,000)
3. Given PO ยอด 5,001 บาท, When ผู้จัดการสาขาเปิด PO, Then ไม่เห็นปุ่มอนุมัติ เห็นข้อความ "รอเจ้าของอนุมัติ" (ไม่มีปุ่มส่งต่อ เพราะระบบส่งให้เจ้าของแล้ว) และเรียก API ตรงได้ 403
4. Given PO ยอด 12,000 บาท, When เจ้าของกดอนุมัติ, Then อนุมัติได้
5. Given PO ถูกแก้ยอดหลังอนุมัติ, Then สถานะกลับเป็น Draft และต้องอนุมัติใหม่ (BR-06)
6. **แจ้งเจ้าของ** — Given PO ยอด 8,500 บาทถูกส่งขออนุมัติ, Then เจ้าของได้รับแจ้งเตือนในระบบ "มี PO รออนุมัติ" 1 ครั้ง พร้อมเลข PO และยอด
