## Story

ในฐานะ **ฝ่ายจัดซื้อ** ฉันต้องการ **สร้าง PDF ของใบสั่งซื้อที่อนุมัติแล้ว เพื่อส่งให้ผู้ขายทาง LINE และบันทึกว่าส่งไปแล้ว** เพื่อให้ **ผู้ขายได้ใบสั่งซื้อที่ถูกต้องเหมือนกันทุกครั้ง และสาขารู้ว่า PO ไหนพร้อมรอรับของ**

## Acceptance Criteria

ข้อมูลตัวอย่าง: PO-2026-0842 · ผู้ขาย บจก. สยามฟาร์มเฟรช · สถานะ Approved · ส่งแยกถึงสาขา 1 และสาขา 3

1. **สร้างได้เฉพาะ PO ที่อนุมัติแล้ว** — Given PO สถานะ Approved, When ฝ่ายจัดซื้อกด "ส่งออก PDF", Then ได้ไฟล์ PDF · Given PO สถานะ Draft หรือ PendingApproval, Then ไม่เห็นปุ่ม และเรียก API ตรงได้ 409
2. **เนื้อหา PDF** — PDF มีเลข PO, วันที่, ชื่อผู้ขาย, รายการพร้อมหน่วยซื้อ จำนวน ราคาต่อหน่วย, ยอดก่อน VAT, VAT, ยอดรวม, ชื่อผู้อนุมัติ และ **จำนวนแยกตามสาขาที่ต้องส่ง** (เพราะผู้ขายส่งแยกถึงแต่ละสาขา ดู US-005)
3. **ส่งเอง ระบบไม่ส่งแทน** — ผู้ใช้ดาวน์โหลดไฟล์ หรือแชร์ผ่านเมนูแชร์ของเครื่องไปยัง LINE ระบบไม่ส่งข้อความหาผู้ขายเอง
4. **ทำเครื่องหมายว่าส่งแล้ว** — When กด "ทำเครื่องหมายว่าส่งแล้ว" และเลือกช่องทาง (LINE / โทรศัพท์ / อื่นๆ), Then PO เป็น Sent และบันทึกผู้ส่ง เวลา และช่องทางใน audit log
5. **ส่งซ้ำได้** — Given PO สถานะ Sent, Then ส่งออก PDF ได้อีก โดยสถานะและเวลาส่งครั้งแรกไม่เปลี่ยน
6. **เริ่มนับวันค้างส่ง** — เวลาที่ PO เป็น Sent คือจุดเริ่มนับ 7 วันของ US-001 AC 8 · PO ที่เป็น Sent จะแสดงในหน้า "PO รอรับของ" ของสาขาที่เกี่ยวข้อง
7. **สิทธิ์** — เฉพาะ role Purchasing และ Owner ส่งออกและทำเครื่องหมายได้ คนอื่นได้ 403

## Out of scope

- ส่ง PO ผ่าน LINE API หรืออีเมลอัตโนมัติ (LINE Notify ปิดบริการแล้ว · LINE Messaging API ต้องตั้ง Official Account และผู้ขายต้องเพิ่มเพื่อน เกินขอบเขต MVP)
- ผู้ขายยืนยันรับ PO ในระบบ
- แก้ PO หลังส่งแล้ว (ต้องยกเลิกและออกใบใหม่ → backlog)
