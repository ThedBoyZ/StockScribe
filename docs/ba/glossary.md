# Glossary (คำศัพท์)

> เจ้าของ: **BA** · ใช้คำเดียวกันทั้งเอกสาร, โค้ด, และ UI

| คำ | ชื่อในโค้ด | ความหมาย ||
| ใบขอซื้อ (PR) | `PurchaseRequest` | สาขาแจ้งว่าต้องการของอะไร เท่าไหร่ ยังไม่ระบุผู้ขาย |
| ใบสั่งซื้อ (PO) | `PurchaseOrder` | ฝ่ายจัดซื้อสั่งผู้ขายจริง ระบุราคา ต้องอนุมัติก่อนส่ง |
| ใบรับของ (GRN) | `GoodsReceipt` | บันทึกของที่ได้รับจริงตาม PO รับบางส่วนได้ |
| ค้างส่ง | `OutstandingQty` | จำนวนที่สั่งใน PO แต่ยังไม่ได้รับ |
| ผู้ขาย | `Supplier` | บริษัทที่ร้านซื้อของด้วย |
| SKU | `Sku` | รหัสสินค้าภายในร้าน ไม่ซ้ำ |
| หน่วยฐาน | `BaseUnit` | หน่วยเล็กสุดที่นับสต็อก เช่น ขวด |
| หน่วยซื้อ | `PurchaseUnit` | หน่วยที่ผู้ขายขาย เช่น ลัง (ลังละ 24 ขวด) |
| ตัวคูณหน่วย | `ConversionFactor` | จำนวนหน่วยฐานต่อหน่วยนั้น เช่น ลัง = 24 |
| ล็อต | `StockLot` | กลุ่มสินค้าที่รับเข้าพร้อมกัน วันหมดอายุเดียวกัน |
| FEFO | — | First Expired, First Out ตัดสต็อกล็อตที่หมดอายุก่อน |
| Reorder point | `ReorderPoint` | ระดับสต็อกที่ต่ำกว่านี้ต้องสั่งเพิ่ม |
| ยอดขั้นต่ำ | `MinOrderAmount` | ยอดเงินขั้นต่ำต่อ PO ที่ผู้ขายยอมส่ง |
| วงเงินอนุมัติ | `ApprovalLimit` | ยอด PO สูงสุดที่ role หนึ่งอนุมัติได้ |
| ของแถม | `IsFree` | บรรทัดสินค้าที่ได้ฟรี ต้นทุนเป็น 0 |
| ปรับสต็อก | `StockAdjustment` | แก้จำนวนสต็อกพร้อมเหตุผล (เสีย, หาย, หมดอายุ) |

## สถานะเอกสาร

**PR:** `Draft` → `Submitted` → `Approved` / `Rejected` → `Converted` (ถูกรวมเป็น PO แล้ว)

**PO:** `Draft` → `PendingApproval` → `Approved` → `Sent` → `PartiallyReceived` → `Closed` / `Cancelled`
