## Story

ในฐานะ **พนักงานสาขา** ฉันต้องการ **ให้ระบบเสนอรายการสินค้าที่ต่ำกว่าจุดสั่งซื้อ พร้อมจำนวนแนะนำ แล้วสร้างเป็นร่าง PR ได้ในคลิกเดียว** เพื่อให้ **ทำรายการขอซื้อประจำสัปดาห์ได้เร็ว และไม่ลืมของที่ใกล้หมด**

## Acceptance Criteria

ข้อมูลตัวอย่าง: สาขา 2 · นม: reorder point 20 ขวด, max stock 60 ขวด, คงเหลือ 12 ขวด, หน่วยซื้อ ลัง = 24 ขวด

1. **แสดงรายการแนะนำ** — Given ข้อมูลตัวอย่าง, When พนักงานกด "สร้าง PR จากของใกล้หมด", Then เห็นนมในรายการ คงเหลือ 12 · จุดสั่งซื้อ 20 · แนะนำ 2 ลัง
2. **สูตรจำนวนแนะนำ** — จำนวนแนะนำ = max stock − คงเหลือ แล้วปัดขึ้นเป็นหน่วยซื้อ (60 − 12 = 48 ขวด = 2 ลัง)
3. **ขอบเขต** — Given คงเหลือ 20 พอดี, Then ไม่แสดง (แสดงเมื่อน้อยกว่า reorder point เท่านั้น)
4. **ไม่แนะนำซ้ำ** — Given นมมี PR ที่ยัง Submitted/Approved หรือ PO ที่ยังไม่ปิดอยู่แล้ว, Then นำยอดที่สั่งค้างมานับรวมกับคงเหลือก่อนคำนวณ ถ้ารวมแล้วไม่ต่ำกว่าจุดสั่งซื้อ ไม่แสดง
5. **แก้ก่อนสร้างได้** — พนักงานติ๊กเลือก/ไม่เลือก และแก้จำนวนแต่ละรายการได้ก่อนกด "สร้างร่าง PR"
6. **ได้ร่าง ไม่ส่งเอง** — When กด "สร้างร่าง PR", Then ได้ PR สถานะ Draft หนึ่งใบ ต้องกดส่ง (Submitted) เองตาม flow ปกติ
7. **สินค้าไม่ได้ตั้งค่า** — สินค้าที่ไม่มี reorder point ไม่ถูกแนะนำ และ Admin เห็นรายงาน "สินค้ายังไม่ตั้งจุดสั่งซื้อ"
8. **สิทธิ์** — พนักงานเห็นเฉพาะสต็อกสาขาตัวเอง

## Out of scope

- สร้าง PR หรือส่งอัตโนมัติโดยไม่มีคนกด
- คำนวณ reorder point จากยอดขายย้อนหลัง (ไม่มีข้อมูลขายจาก POS)
- ปรับตามฤดูกาล เช่น ธันวาคมยอดเพิ่ม 2 เท่า (#003 ข้อ 14) → backlog
