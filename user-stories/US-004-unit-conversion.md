## Story

ในฐานะ **พนักงานสาขา** ฉันต้องการ **เลือกหน่วยของสินค้าจากรายการที่กำหนดไว้ตอนสร้าง PR** เพื่อให้ **ฝ่ายจัดซื้อสั่งของได้ถูกจำนวน ไม่สั่งผิดหน่วยจนของล้นโกดัง**

## Acceptance Criteria

ข้อมูลตัวอย่าง: น้ำอัดลม A · หน่วยฐาน = ขวด · แพ็ค = 6 ขวด · ลัง = 24 ขวด · หน่วยซื้อจากผู้ขาย = ลัง

1. **เลือกหน่วยจากรายการ** — Given สร้าง PR เพิ่มน้ำอัดลม A, When กดช่องหน่วย, Then เห็นตัวเลือก ขวด / แพ็ค / ลัง เท่านั้น พิมพ์หน่วยเองไม่ได้
2. **แสดงจำนวนหน่วยฐาน** — Given เลือก 10 แพ็ค, Then บรรทัดนั้นแสดง "= 60 ขวด" ใต้ช่องจำนวน
3. **แปลงเป็นหน่วยซื้อ (ปัดขึ้น)** — Given PR ขอ 30 ขวด, When ฝ่ายจัดซื้อดูรายการรอสั่ง, Then แสดง "ขอ 30 ขวด → สั่ง 2 ลัง (48 ขวด) เกิน 18 ขวด"
4. **ลดจำนวนได้** — Given ข้อ 3, When ฝ่ายจัดซื้อแก้เป็น 1 ลัง, Then บันทึกได้ และแสดง "ขาด 6 ขวด" เป็นข้อความเตือน (ไม่บล็อก)
5. **จำนวนต้องเป็นบวก** — Given กรอก 0 หรือติดลบ หรือทศนิยมในหน่วยที่นับเป็นชิ้น, Then บันทึกไม่ได้ (API 422)
6. **สินค้ายังไม่ตั้งหน่วยซื้อ** — Given สินค้ามีแค่หน่วยฐาน ไม่มีหน่วยซื้อ, Then PR สร้างได้ด้วยหน่วยฐาน แต่ฝ่ายจัดซื้อเห็นป้าย "ยังไม่ตั้งหน่วยซื้อ" และสร้าง PO สำหรับบรรทัดนั้นไม่ได้จนกว่า Admin จะตั้งค่า
7. **เก็บค่าตามจริง** — PR เก็บทั้งหน่วยที่ผู้ขอเลือก จำนวน และจำนวนในหน่วยฐาน แก้ตัวคูณภายหลังต้องไม่ทำให้ PR เก่าเปลี่ยนตัวเลข
8. **ใช้บนมือถือ** — หน้าสร้าง PR ใช้ได้ที่จอ 360px

## Out of scope

- หน่วยน้ำหนัก/ปริมาตรที่เป็นทศนิยม (กก., ลิตร) ของชั่งน้ำหนัก
- หน่วยซื้อต่างกันตามผู้ขาย (ผู้ขาย A ลังละ 24, ผู้ขาย B ลังละ 12) → backlog
- แปลงหน่วยตอนรับของ (ใช้หน่วยซื้อของ PO)
